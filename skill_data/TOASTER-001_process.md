## 4. 工时汇总

### 单件纯加工时间

不含 Setup，仅累计各工序的单件加工时间：

- 总加工时间：**285 秒/件**
- 即：**4.75 分钟/件**

### 单批 Setup 时间

若每个工序在一批生产开始时各执行一次 Setup：

- 总 Setup 时间：**90 分钟/批**

### 批量生产总资源工时

若一批生产 `Q` 件，则理论总资源占用时间为：

```text
总时间（分钟）
= 总 Setup 时间 + Q × 单件总加工时间（分钟）
= 90 + Q × 4.750000
```

也可以写成：

```text
T(Q) = 90 + 285 × Q / 60
```

这里的“总资源工时”是把各工序的工作站占用时间相加，用于产能计算；它不等同于实际日历完工时长，因为不同订单、不同工作站之间可能存在并行、等待、排队和换线。

## 5. 制作过程文本总结

生产 1 件 **烤面包机（TOASTER-001）**，需要先按 BOM 准备上述原料，然后按照 Routing 中定义的顺序依次经过各工作站。

整个流程包含 6 道主要工序。单件纯加工时间合计约 **4.75 分钟**；如果按批生产，还需要额外考虑各工序合计 **90 分钟/批** 的 Setup 时间。

在后续 APS / CP-SAT 排程中，可以将原料用量作为 Material Constraint，将工序顺序作为 Precedence Constraint，将工作站作为 Resource Constraint，将 Setup 与加工时间作为 Duration，将 Work Center Capacity 作为产能约束。
